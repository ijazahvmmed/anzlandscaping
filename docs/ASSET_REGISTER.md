No before/after claim is made. Service imagery is labelled as service context rather than a new executed project.

Old `placeholder-image`, Elementor placeholder, icon decks, unsupported certificates/awards and review graphics are excluded from the designed pages. The downloaded media directory retains several unused candidates for editorial selection; retrieval from the ANZ domain does not prove ownership or publication permission.

The supplied colour and black logo exports were proportionally resized for web delivery without changing their shapes. The blank-looking Artboard 23 is not used. CSS creates a white presentation from the supplied black logo. Source logo files remain in Downloads.

Satoshi Regular, Medium and the original variable candidate were obtained directly from `https://api.fontshare.com/v2/fonts/download/satoshi`. The production CSS uses the unmodified static Regular/Medium files for consistent WebKit rendering. Fontshare’s bundled `FFL.txt` permits own-site self-hosting and restricts redistribution. The fonts are included only for this private ANZ website handoff; do not publish this as a general template/font repository. Third parties should obtain their own copy directly from Fontshare.

The leaf artwork, planter/plant/water icons, SVG aperture and orbit lettering are code-native vectors created for the design. They do not replace the ANZ wordmark.
